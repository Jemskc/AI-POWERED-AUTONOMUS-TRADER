# 100-coin low-turnover market-neutral coin ranking: 2026-09-26

Real Binance hourly data. Universe: at every hour, the 100 coins with the highest trailing-30-day median trading volume (point in time, from ~250 candidates) that have >= 60 days of history. Model: LightGBM regression on the cross-sectional rank of the next-24h return (price/volume features, same feature code as the live engine). Walk-forward: 6-month test blocks from 2021-07, expanding window, purged. Portfolio (PRIMARY, fixed before testing): daily rebalance; 3-day EWMA of predictions; long when a coin's rank enters [70%, 98%] and hold while >= 55%; short when it enters [2%, 30%] and hold while <= 45%; inverse-volatility weights, 50% long / 50% short; 7bp per side on turnover.
